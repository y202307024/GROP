## 6.1 테스트 케이스와 결과

평가 지표([02-요구사항 2.6](02-요구사항.md#26-평가-지표-검수-목표))를 바탕으로 대표 시나리오를 정해 수동 검수했습니다.

| TC | 검수 항목 | 대표 시나리오 / 통과 기준 | 결과 |
|:--:|---|---|---|
| TC-01 | 인증·초대 | 미로그인 상태에서 초대 링크 → 가입·프로필 설정 후 복귀 / 같은 그룹 참여, 중복 멤버 없음 | 조건부(계정 소유)로 작동 |
| TC-02 | 프로필 | 기본 프로필 변경 후 그룹 프로필 적용·제거 / 설정과 기본 대체 규칙 일치 | 구성 일치 |
| TC-03 | 권한 | 타 그룹 ID로 목록·API 접근, 멤버의 공지 등록 시도 / UI와 서버 모두 차단 | 권한 분리 |
| TC-04 | 회의·채팅 | 2인 이상 음성·마이크 제어·채팅·퇴장·재입장 / 참여자 상태 일치 | 회의방 상태 보존 |
| TC-05 | 동시 편집 | 같은 객체 편집·연결 끊김·재접속 / 유실·중복 없이 저장 상태로 복구 | 소유 권한 분리 |
| TC-06 | 녹화 | 10분 녹화, 업로드 실패·재시도 / 재생 가능, 음성 포함 | 녹화본 정상 재생 |
| TC-07 | AI 요약 | 한글 회의 요약, 중복 요청, 실패, 수정 후 저장 / 수정본 유지, 근거 대조 가능 | 요약본 수정 가능, 논점 중심 요약 |
| TC-08 | 타임스탬프·타임랩스 | 챕터 클릭 이동 / 속도 변경·공백 압축·저장·삭제 | 챕터 정상 이동 |
| TC-09 | 화면 대응 | 너비 1000~2560px, 높이 560~1080px / 전체 화면 스크롤 없음 | 정적 복제본 검증 통과 |
| TC-10 | 문서 관리 | 목록·검색(문서명·회의명)·첨부 다운로드, 작성자 외 수정 시도 / 결과 일치, 수정은 작성자만 | 수정 권한 분리 |
| TC-11 | 캘린더 | 일정 등록·수정·삭제, 반복 일정 표시 / 새로고침 후 유지(같은 브라우저) | 일정 데이터 유지 |

## 6.2 성능 확인

- **동시 접속**: 회의방 동시 접속 80명까지 확인했습니다 (5주차).
- **한국어 음성 인식**: 사용 모델 Whisper large-v3의 공개 벤치마크(FLEURS) 기준 문자 오류율 5.31%, 정확도 약 95%입니다. 팀이 직접 측정한 값은 아닙니다.
- **요약 처리 시간**: 1시간 회의 기준 약 2분 (Groq 처리 속도를 바탕으로 한 예상치)
- **AI 요약 용량**: 오디오를 16kHz 모노 mp3로 줄여 Whisper 25MB 한도 안에서 처리합니다.

## 6.3 추진 일정 대비 실제 수행

| 주차 | 계획 작업 | 계획 산출물 | 실제 수행 |
|:--:|---|---|---|
| 1 | 기존 코드 확인, 요구사항 확정, 기술 검증 | 범위표, 위험 목록 | 기획서 작성 및 Figma 제작 |
| 2 | 화면 구조, 공통 UI·DB·권한 설계 | 화면 목록, 스키마 | 기획서 기반 설계 |
| 3 | 인증, 프로필, 그룹, 초대, 멤버 관리 | 인증과 그룹 기능 | Google·GitHub 계정 연동, 사용자별 권한 분리 |
| 4 | 화이트보드 도구, 저장, 개인/그룹 보드 구분 | 보드 기능 | 화이트보드 도구 8개, 신규/기존 보드 선택 |
| 5 | 실시간 동기화, 음성, 채팅, 보드 선택 | 2인 이상 회의 | 80명 동시 접속 확인 |
| 6 | 녹화, 업로드, 영상 재생, 회의록 목록 | 저장과 재생 검증 | 클라우드·서버로 녹화 전송 및 저장 |
| 7 | 전사, AI 요약, 편집, 실패 재시도 | 원본 대조 가능한 요약 | 주제 중심 요약 결과 확인 |
| 8 | 타임랩스, 챕터, 기본 문서 출력 | 기록 재사용 흐름 | 타임랩스·채팅 기록·발언자별 기록 확인 |
| 9 | 일정, 알림, 설정, 검색 중 P1 선택 구현 | 핵심 완료 후 확장 | 다중 일정 관리, 알림 설정 |
| 10 | 통합, 권한, 브라우저·UI 테스트, 버그 수정 | 결함 목록, 검수 결과 | 반복 테스트 및 검수 |
| 11 | 회귀 검수, 배포 준비, 시연, 보고서 | 최종 웹, 보고서, 발표 자료 | 배포 완료, 보고서 작성 완료 |
