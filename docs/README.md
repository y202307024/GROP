# GROP 프로젝트 문서

> 실시간 음성 회의·화이트보드·채팅·녹화에 AI 서기(회의 요약)를 결합한 그룹 회의 웹 서비스 — 2026 유한대학교 컴퓨터소프트웨어전공 캡스톤디자인(졸업작품)

이 폴더는 소프트웨어 개발 7단계(문제정의 → 요구사항 → 설계 → 구조생성 → 구현 → 테스트 → 수정 및 문서화)에 따라 GROP의 산출물을 정리한 문서입니다. 내용은 캡스톤디자인 작품 완료 보고서와 `CLOUD` 브랜치 소스 코드(프론트 `src`, Express `server`, Cloudflare `worker`, DB `supabase`)를 기준으로 작성했습니다.

| 단계 | 문서 | 주요 산출물 | UML·다이어그램 |
|:--:|---|---|---|
| 1 | [01-문제정의](01-문제정의.md) | 문제 정의, 시장 근거, 경쟁 비교, 목표, 범위(In/Out), 기대효과 | Activity |
| 2 | [02-요구사항](02-요구사항.md) | 사용자 시나리오, MoSCoW, 개발 단계(P0~P2), 평가 지표 | Use Case |
| 3 | [03-설계](03-설계.md) | 아키텍처, ERD, API 명세, 주요 흐름, 권한, 화면 설계 | Sequence, ERD |
| 4 | [04-구조생성](04-구조생성.md) | 기술 스택, 구성 요소 역할, 폴더 구조, 코딩 규칙, 브랜치 전략 | Component, Deployment |
| 5 | [05-구현](05-구현.md) | 기능별 구현 내용, 핵심 로직, 시연 GIF, 화면 캡처 | State |
| 6 | [06-테스트](06-테스트.md) | 검수 항목과 결과, 추진 일정 대비 실제 수행 | – |
| 7 | [07-수정및문서화](07-수정및문서화.md) | 한계와 개선 백로그, 운영 메모, 기대효과 달성도 | Package |
